What rcab is

A ride-hailing platform with normal, shared and scheduled rides, run on one VPS in Phase 0

Passenger web app

Next.js 14. Quote a route, book now or later, share a cab, track the driver live, cancel, rate.

Driver app

Flutter on Android. Register a vehicle, go online, accept offers, run solo trips and shared itineraries.

API and ops

NestJS on Postgres, Redis and OSRM, with Grafana, Prometheus, Loki and Uptime Kuma beside it.

Details: docs/onboarding/01-system-overview.md · Scope rule: ADR-0009, single VPS

Phase 0 is deliberately one VPS and one docker-compose. Anything multi-host is out of scope until a decision says otherwise. Cancellation is free in Phase 0, and shared fares are fixed at join until story E8.S9 decides the real policy.
