Two fixes came out of this scene. The API booted Nest with its logger switched off, so every dispatch, reconciler and outbox warning was silently dropped; Nest now logs through pino, with secrets redacted. And request_id was a Loki label, which created one stream per request; it is now a parsed JSON field.
