Recovery and sign-out

W09 · 51 s · reload and reconnect restore tracking from a snapshot

W10 · 18 s · logout revokes the refresh token on the server

functionality/realtime-protocol.md · functionality/auth-and-sessions.md

On reconnect the client re-subscribes and the server sends a versioned snapshot from Postgres; any event older than what the client already applied is dropped. Sign-out calls the logout endpoint, so a reload cannot silently restore the session.
